SimReady assets that just load in three.js.

NVIDIA's SimReady library ships as layered USD, which browsers cannot read. These are seven of those assets, converted to GLB — true metric scale, meshopt geometry, WebP textures — plus the small module that puts them in your scene.

Use it

From a CDN, no build step

Drop this into any page that already uses three.js modules.

<!-- import map, once -->
<script type="importmap">{"imports":{
  "three": "…/three.module.js",
  "three/addons/": "…/examples/jsm/"
}}</script>

import { createLoader, loadAsset } from
  'https://cdn.jsdelivr.net/gh/imsarah/simready-threejs@main/src/simready-threejs.js'
import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js'
import { MeshoptDecoder } from 'three/addons/libs/meshopt_decoder.module.js'

const loader = createLoader({ loaderClass: GLTFLoader, meshoptDecoder: MeshoptDecoder })

const { object, meta } = await loadAsset('cart_mobile_e01', {
  loader, THREE, floor: true,
})
scene.add(object)
console.log(meta.measured.size) // { x: 0.401, y: 1.579, z: 0.838 }

Or straight from the manifest

Every file is a plain GLB — no library needed if you already have a loader.

const CDN = 'https://cdn.jsdelivr.net/gh/imsarah/simready-threejs@main/'

// any loader with a meshopt decoder
loader.load(CDN + 'assets/box_corrugated_brown_b08.glb',
  (gltf) => scene.add(gltf.scene))

// catalogue: real dimensions + triangle counts
const manifest = await (await fetch(
  CDN + 'manifest.json')).json()
manifest.assets['cart_mobile_e01'].size_m
// → { x: 0.401, y: 1.579, z: 0.838 }
  • Y-up, 1 unit = 1 metre. No rescaling by eye.
  • meshopt + WebP — needs MeshoptDecoder; textures are WebP, fine in every modern browser.
  • No physics. Render geometry only — colliders stay in the SimReady USD.

Worth knowing

  • Converted, not exported by hand. The converter walks the composed USD stage, bakes prototype instances, and rebuilds indexed UVs — the three traps that break naive conversion.
  • 64–99% smaller than the source USD folders (the cart is 142 MB on Hugging Face, 1.16 MB here).
  • Verified against published ground truth. An eighth asset converted blind (eyeglasses) matched the reference exactly: 4 meshes, 42,168 triangles.
  • MDL-only assets will fail silently. Only UsdPreviewSurface materials convert; always eyeball output.
  • Default variant only. SimReady physics variants (rigid/deformable) are not selectable yet.
  • Props, not scenes. Single assets up to ~300K triangles; nested assemblies are untested.
